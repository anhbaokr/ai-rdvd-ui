# AI RDvD UI V32 — Cài đặt ứng dụng

Nút ⚙ trên topbar mở modal Cài đặt thật.

- Chung: ngôn ngữ, theme, bật/tắt shortcut, giảm chuyển động.
- Phát lại: bước tua 1–15 giây, loop playback, mute khi import.
- Giao diện: tự hiện khung subtitle khi import, tùy chọn mở bảng subtitle khi khởi động.
- Timeline: zoom mặc định 50–400%.
- Phím tắt: danh sách shortcut hiện hành.
- Thiết lập lưu bằng localStorage và áp dụng ngay.
- Khôi phục mặc định.
- ESC hoặc click vùng ngoài modal để đóng.
- CC vẫn chỉ điều khiển khung subtitle AI RDvD.
