# AI-RDvD UI V30 — CC / AI Subtitle Frame Fix

- CC now controls the AI-RDvD subtitle frame/overlay only.
- Closing the Subtitle Settings panel does not hide the subtitle frame.
- CC OFF hides the AI subtitle frame and AI subtitle layer.
- CC ON restores the frame/layer.
- No hard-sub mask is created or controlled by CC.
- Importing a new video resets the AI subtitle frame to visible.
