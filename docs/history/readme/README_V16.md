# AI RDvD UI V16

V16 giữ nguyên menu/ngữ cảnh "Tùy chỉnh phụ đề" đang có trong header của khung preview.
Không thêm nút/menu phụ đề mới trên topbar.

Phím tắt:
- Ctrl + Shift + L: đổi Việt / English
- Ctrl + Shift + T: đổi Sáng / Tối
- Ctrl + Shift + S: ẩn / hiện panel Tùy chỉnh phụ đề hiện có

Phím tắt Ctrl+Shift+S được hiển thị ngay trên nút "Tùy chỉnh phụ đề" hiện có.
